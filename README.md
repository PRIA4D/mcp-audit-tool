## 📋 Key Features Explained

Let's break down what this tool actually checks:

### Tool Poisoning Detection
Some bad actors create MCP tools that look helpful but actually do harmful things. The scanner checks if any tool matches known dangerous patterns.

### Secret Leak Detection
If your configuration has passwords, API keys, or tokens in plain text, the tool flags them. It's like finding a key left under the doormat.

### Command Injection Protection
This looks for sneaky commands hidden in the setup that could run without your permission. Think of it as checking for hidden trapdoors.

### Supply Chain Risk Assessment
If your MCP server uses other software packages, this checks if those packages are from trusted sources. It's like checking the "best before" date on groceries.

### Prompt Injection Scanner
AI systems use "prompts" (instructions). This checks if any prompt tries to make your AI do something it shouldn't, like accessing sensitive files.
